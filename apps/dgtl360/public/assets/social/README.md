# Social brand icons

Locally served SVGs extracted from Iconify's maintained npm collections:
- @iconify-json/logos 1.2.14: YouTube, TikTok, Slack (SVG Logos, CC0).
- @iconify-json/simple-icons 1.2.95: Instagram, WhatsApp, Threads, X (Simple Icons, CC0).
- @iconify-json/fa6-brands 1.2.6: LinkedIn, Telegram (Font Awesome Free by Fonticons, Inc., CC BY 4.0).

Sources: https://github.com/gilbarbara/logos, https://github.com/simple-icons/simple-icons,
https://github.com/FortAwesome/Font-Awesome.
Font Awesome attribution: https://fontawesome.com/ — https://creativecommons.org/licenses/by/4.0/
Monochrome icons are rendered in white or black for the existing footer badges. Brand trademarks belong to their respective owners.
